# Этап 3: генератор рынка в AssemblyScript

Выполнен 2026-10-06.

## Реализовано

- Полный ABI версии 1: memory, abiVersion, init, generateBatch и getBatchLength.
- PRNG xorshift32 внутри Wasm, с сохранением состояния и заменой seed 0 на `0x6d2b79f5`.
- Состояние bid по каждому из 1–50 инструментов; начальные цены `10000 + instrumentId × 1000` центов.
- Выбор инструмента, шага bid −5…+5, спреда 1…20, стороны сделки и объёмов выполняется в AssemblyScript. Повторения инструмента в пакете разрешены.
- Bid ограничен 1…1 000 000 центов; цена сделки равна bid или ask. Trade quantity находится в 1…1000, book quantities — в 0…10 000.
- Пакеты 1–1000 записей используют один статический буфер 28 000 байт. Каждая запись содержит семь little-endian u32 в порядке MarketUpdate.
- init полностью сбрасывает корректный запуск: цены, PRNG, длину и содержимое буфера. Ошибочный init возвращает 1 и сохраняет предыдущий запуск.
- Ошибочный generateBatch и вызов до init возвращают 0 с нулевой длиной; PRNG, цены и данные буфера не изменяются.
- Worker создаёт свежий seed через crypto.getRandomValues, вызывает init и только после успеха отправляет ready. Загрузчик проверяет все функции генератора.

## Проверки

| Проверка | Результат |
| --- | --- |
| `npm test` | 25 Node-тестов настоящих debug/release бинарников и 18 тестов Vitest проходят. |
| Размеры и значения | Все размеры пакетов 1–1000; для каждого count 1–50 проверены диапазоны, базовые цены, порядок полей и непрерывность bid. |
| Воспроизводимость | Независимые экземпляры и debug/release дают одинаковые последовательности при одинаковом seed. Другие seed дают другие данные; seed 0 соответствует фиксированной ненулевой замене. |
| Продолжение состояния | Разбиение одного потока на разные размеры пакетов не меняет последовательность. |
| Сброс и ошибки входных данных | Повторный init после смены count/seed воспроизводит исходную последовательность; invalid init/batch не изменяют активный поток. |
| Границы цен | Память инструмента контролируемо установлена у нижней и верхней границы; настоящий Wasm сохраняет ограничения. Тестовые экспорты в production не добавлены. |
| Ресурсы | Для каждого бинарника после 2000 максимальных пакетов сохраняются тот же адрес буфера и та же память размером 64 KiB. |
| `npm run lint` | Успешно. |
| `npm run build:pages` | Успешно; настоящий бинарник скопирован без изменений. |
| Production-браузер в подпапке Pages | Полный генератор загружается и успешно инициализируется внутри Worker. |

## Границы этапа

Генератор готов и протестирован, но непрерывное расписание вызовов и отправка метрик ещё не подключены. Этап 4 реализует накопление показателей, этап 5 — Worker-производитель. Страницы пока отображают статус инициализации и заготовки будущего интерфейса; Pause/Resume и Apply относятся к последующим этапам.

Статическая память использует официальный API [AssemblyScript memory.data/load/store](https://www.assemblyscript.org/stdlib/globals.html).
