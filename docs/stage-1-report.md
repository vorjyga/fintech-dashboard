# Этап 1: каркас и воспроизводимая сборка

Выполнен 2026-10-06.

## Реализовано

- Angular 21, strict mode, standalone-компоненты и OnPush; без SSR.
- Общий контейнер, Material-навигация, ленивые страницы dashboard/settings.
- Hash routing; пустой и неизвестный маршрут перенаправляются на dashboard.
- Светлая тема Material с синим акцентом и системными шрифтами.
- Tailwind CSS 4 через PostCSS, без Preflight, отдельно от SCSS Material.
- Общие контракты настроек, обновлений, снимков, Wasm ABI и Worker-сообщений.
- Отдельные директории для AssemblyScript, Worker и корневого сервиса; AssemblyScript исключён из Angular TypeScript.
- Lock-файл, Node.js в `.nvmrc`, ESLint, Vitest, команды сборки и тестирования.
- Английский README и таблица соответствия требованиям английского оригинала ТЗ.

## Проверки

| Проверка | Результат |
| --- | --- |
| `npm ci` с Node.js 22.13.1 и npm 10.9.2 | Успешно; 0 найденных уязвимостей. |
| `npm start -- --host 127.0.0.1` | Dev server запускается на порту 4200. |
| `npm run build` | Успешная production-сборка; начальный пакет около 286 kB. |
| `npm run build:pages` | Успешно; base href `/fintech-dashboard/`. |
| `npm test` после чистой установки | 2 теста Vitest проходят: навигация и ленивые маршруты с fallback. |
| `npm run lint` | Успешно. |
| Production-сборка в браузере | Dashboard и Settings открываются; переход через Material-кнопку работает. |
| Прямая загрузка Pages-пути | `/fintech-dashboard/#/settings` работает; `#/unknown` перенаправляется на `#/dashboard`. |
| Desktop 1280 px | Header использует row; Material theme и системный шрифт применены. |
| Mobile 375 px | Header использует column, настройки идут одной колонкой; scrollWidth = 375 px. |
| Визуальная проверка | Скриншоты desktop/mobile просмотрены; Material и utility-раскладка корректны. |

Первоначально production-сборка аварийно завершалась внутри песочницы; запуск вне неё прошёл. При установке Vitest npm некорректно разрешал optional peer-зависимости разных основных версий. Overrides фиксируют Vitest и browser peer на 4.1.11; чистая установка npm 10.9.2 проверена.

## Границы этапа

Wasm ещё не компилируется и не выполняется: `build:wasm` явно сообщает об отложенной реализации и не создаёт фиктивный бинарник. Подключение компилятора и минимального модуля относится к этапу 2. Worker и сервис управления пока представлены директориями и общими контрактами. Страницы показывают заготовки; реальные данные, форма Apply, Pause/Resume и деплой относятся к следующим этапам.
