# Этап 9 — интеграционные проверки

Production-артефакт проверен Chromium через agent-browser по адресу http://localhost:4300/fintech-dashboard/. Настоящий Worker загружает release Wasm; bigint-снимки обновляют Material Table.

| Проверка | Результат |
| --- | --- |
| lint / тесты | 25 Node-тестов обоих настоящих Wasm и 72 Angular/Vitest-теста проходят. |
| Production Pages build | Префикс /fintech-dashboard/; Worker, Wasm и lazy chunks загружаются. |
| Полный сценарий | Старт, накопление, Settings, редактирование без Apply, возврат, Pause, навигация, Resume и Apply работают. |
| Навигация | Worker не создаётся повторно; paused/running и итоги сохраняются. Неотправленный черновик сбрасывается. Дополнительно проверено RouterTestingHarness с fake Worker. |
| Быстрые Apply | Два синхронных submit, второй во время загрузки: старые Worker terminate, последняя конфигурация 2 инструмента активна. Старые snapshot/status/error/ready дополнительно покрыты сервисными тестами. |
| Ошибка и Retry | Тестовый URL отсутствующего Wasm даёт видимый HTTP 404; после восстановления URL Retry запускает производителя с последними настройками. |
| Максимальная нагрузка | 50 / 1000 / 50 мс, 50 строк, навигация и поля отзывчивы. Минимальный наблюдавшийся интервал обычных снимков около 102 мс. Объём продолжает расти; во время Pause снимки прекращаются. |
| Ресурсы | Browser-инструментирование Worker подтверждает terminate старых запусков. Тесты контроллера проверяют отмену таймеров/fetch, тесты сервиса — снятие подписок. |
| Mobile / desktop | 375×812 и 1440×900: форма в одну/три колонки, горизонтальная прокрутка только внутри таблицы. Числа выровнены вправо. |
| Material + Tailwind | Проверены поля, ошибки, кнопки, Progress Bar, Snackbar и клавиатурный focus-visible. Базовые отступы заголовков/параграфов перенесены в CSS layer base, чтобы utilities работали. Preflight не подключён. |
| Reload Settings | Прямой hash-маршрут работает; defaults 5 / 100 / 500 мс восстанавливаются. |

Проверка производительности — browser smoke, а не формальный benchmark. Постоянного E2E-набора нет, как допускает ТЗ. История сделок не хранится: состояние пропорционально числу инструментов, буфер Wasm фиксирован.
